## 🛠️ Advanced Configuration

```env

DEBUG=True/False

FAISS_INDEX_PATH=path/to/index

```

### Command Line Options
```bash

python run.py --production         # Production mode

python run.py --help               # Show help
```

## 📊 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | Homepage |
| POST | `/search` | Perform search |
| GET | `/api/filters` | Get filter options |

### Search Endpoint Example

**Request:**
```json
POST /search
{
    "query": "mercy",
    "limit": 10,
    "book": "Sahih Al-Bukhari",
    "chapter": "Faith",
    "sort_by": "relevance"
}
```

**Response:**
```json
{
    "query": "mercy",
    "results": [...],
    "total_results": 10,
    "processing_time": 0.123,
    "success": true
}
```

**Slow search**
- Check FAISS index size
- Consider GPU acceleration

**CSS not loading**
- Clear browser cache
- Check static file paths
